# Routable resources

</div>

†his plugin allows you to easily create routable entities in Sylius with all the necessary components such as entities, repositories, controllers, admin CRUD interfaces, front-end routes, and CMS features.

You can generate a new Sylius resource (Symfony Entity) with the following command:

```bash
php bin/console make:happy-cms:generate-cms-model
```

With this command you will be able to generate a new Sylius resource (Symfony Entity) with generated files and configuration.
Entity, Repository, Admin CRUD, Front-end routes and controllers, CMS features

Example :
- Generate a Blog
- Generate Faq pages
- Generate Brand page
- Page based on custom Symfony entities
